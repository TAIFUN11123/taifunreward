# Бот-розыгрыш подарков

Как в примере со скрина: бот сидит в чате, и на каждое сообщение с очень маленьким
шансом (по умолчанию 0.1%) объявляет автора победителем и пишет, что подарок отправлен.

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot`, получишь токен вида
   `123456789:AAAAbbbbCCCCddddEEEEffffGGGGhhhh`.
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Пропиши токен через переменную окружения (или впиши прямо в bot.py вместо
   `ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER`):
   ```
   export BOT_TOKEN="твой_токен"
   python bot.py
   ```
4. Добавь бота в свой чат/группу и сделай его **администратором** (чтобы он видел
   все сообщения — в группах с обычными правами боты видят не все сообщения, если
   отключён "privacy mode"; либо отключи privacy mode у @BotFather через
   `/setprivacy` → Disable).

## Что можно настроить (в начале bot.py)

- `WIN_CHANCE` — шанс выигрыша на каждое сообщение (0.001 = 0.1%).
- `GIFTS` — список подарков, которые может "выиграть" человек (название + эмодзи).
- `GIFT_SENDER_USERNAME` — от чьего имени идёт подарок (пишется в сообщении о победе).
- `COOLDOWN_SECONDS` — минимальный промежуток между победами в одном чате, чтобы
  выигрыши не сыпались подряд один за другим.

## Важно про реальную отправку подарков

Этот бот **объявляет** победителя в чате (как текст "Ты выиграл Мишка 🧸").
Но он не отправляет реальный Telegram-подарок (Stars gift) на аккаунт человека —
для этого нужно:
- либо ты сам вручную отправляешь Stars-подарок победителю через приложение Telegram,
- либо (сложнее) подключать Bot API метод отправки подарков (Stars), для чего у бота
  должен быть баланс Stars и включённая соответствующая функция — это отдельная
  доработка, скажи если нужно её сделать.

## Запуск 24/7

Локальный запуск (`python bot.py`) работает, только пока открыт терминал/сервер.
Чтобы бот работал постоянно, разверни его на любом сервере (VPS) или бесплатном
хостинге типа Railway / Render, и запускай через `screen`/`systemd`/Docker, чтобы
процесс не завершался.
